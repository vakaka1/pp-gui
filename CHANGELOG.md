# Changelog

## [1.0.1] — 2026-06-30

Обновление управления веткой `pp-client`.

### Добавлено

- **Выбор ветки обновлений pp-client**: на экране «О программе» появился переключатель между стабильной и предрелизной веткой.
- **Поддержка pre-release обновлений**: при выборе предрелизной ветки GUI запрашивает общий список GitHub Releases и учитывает pre-release версии pp-client.
- **Синхронизация с CLI**: переключение выполняется через штатную команду `pp-client choice release/prerelease`, а текущее состояние читается из общего файла `update-channel`.
- **Автообновление статуса**: после смены ветки GUI сразу перезагружает информацию о доступной версии.
- **Доступность переключателя**: выбор ветки доступен для установленного `pp-client` и не требует наличия обновлений.
- **Чистая панель обновлений**: из интерфейса убрана строка с путем к бинарнику `pp-client`.

### Исправлено

- **Windows stop**: исправлена подстановка PID при аварийной остановке дерева процессов `pp-client`.

## [1.0.0] — 2026-05-06

Первый стабильный релиз PP GUI.

### Добавлено

- **Установщики**: самораспаковывающийся `.bin` для Linux (makeself) и `.exe` для Windows (Inno Setup) — устанавливают приложение в системные каталоги, создают ярлыки
- **Самообновление GUI**: кнопка «Обновить GUI» на экране «О программе» — скачивает новую версию и перезапускает приложение без участия пользователя
- **Системный трей**: приложение сворачивается в трей вместо закрытия, работает в фоне
- **Полный туннель**: запуск `pp-client` с `--full-tunnel`, управление маршрутизацией трафика
- **Управление конфигами**: импорт из файла, буфера обмена, `ppf://` URI; редактирование формой или напрямую в JSON; удаление
- **Тестирование профилей**: запуск `pp-client test` с отображением результата и пинга
- **Логи в реальном времени**: потоковый вывод stdout/stderr `pp-client`
- **Автоустановка pp-client**: скачивание и установка `pp-client` прямо из GUI при первом запуске
- **Обновление pp-client**: через команду `pp-client update` из интерфейса
- **Тёмная тема**: современный тёмный интерфейс с Material 3
- **CI/CD**: автоматическая сборка и публикация релизов по тегу `v*`

### Платформы

- Linux (Ubuntu, Fedora, Arch, Debian и любые другие с GTK 3)
- Windows 10 / 11
