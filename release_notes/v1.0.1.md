PP GUI v1.0.1
v1.0.1: обновление управления веткой pp-client.

Выбор ветки обновлений pp-client: на экране «О программе» появился переключатель между стабильной и предрелизной веткой.

Стабильная ветка: GUI использует обычный последний релиз pp-client и оставляет поведение по умолчанию.

Предрелизная ветка: GUI учитывает pre-release версии pp-client и показывает их как доступные обновления.

Переключение выполняется через штатную команду pp-client choice release/prerelease, поэтому GUI использует тот же механизм, что и CLI.

Текущая ветка читается из общего файла update-channel, чтобы состояние в GUI и pp-client не расходилось.

После смены ветки список обновлений обновляется автоматически.

Для старых версий pp-client, где команды choice еще нет, GUI показывает понятное disabled-состояние.

Исправлена подстановка PID при остановке Windows-процесса pp-client.
